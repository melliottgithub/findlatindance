# FindLatinDance

The premier global portal uniting all Latin social dance cultures: Salsa, Bachata, Brazilian Zouk, Kizomba, and Merengue worldwide.

Part of the Global Latin Dance Triad:
- **[FindLatinDance.com](https://findlatindance.com)**: The Global Umbrella Portal & Multi-Room Congress Discovery
- **[FindSalsa.com](https://findsalsa.com)**: The Salsa Authority (On1, On2, Cuban Casino, Cali)
- **[FindBachata.com](https://findbachata.com)**: The Bachata Authority (Sensual, Traditional, Fusion)

## Architecture
- **Framework**: Next.js 16 (Turbopack, App Router, React 19)
- **Styling**: Tailwind CSS v4, Obsidian & Champagne Gold Theme
- **Hosting**: AWS S3 + CloudFront Edge OAC (`d3lke0hmqtyrnv.cloudfront.net`) + Cloudflare Free DNS
- **Testing**: Vitest catalog integrity test suite
